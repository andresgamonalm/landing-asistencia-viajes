# Landing · Seguro de Asistencia en Viajes · Zurich Chile

**Borrador para revisión interna. No es la página publicada de Zurich.**

- La campaña del encabezado (descuento y fechas) es un ejemplo, no una promoción vigente.
- Los códigos POL / CAD de la Comisión para el Mercado Financiero están pendientes.
- Los precios de las tarjetas son referenciales, tomados del cotizador en octubre de 2026.

El archivo `index.html` es autónomo: todo el CSS, los íconos y la fotografía
van dentro. El buscador envía los datos al motor de cotización de Universal Assistance.

Para editar los textos sin tocar el código, abre la página agregando `?editar` a la dirección.
